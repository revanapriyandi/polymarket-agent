# Internal API contract

All `/api/*` routes except health and Better Auth require the single owner session. JSON success envelopes are direct values; errors are `{error: string, code?: string}`. Decimal currency and token IDs remain strings. Browser uses relative same-origin paths and credentials. Writes require `Origin` matching APP_ORIGIN. Sensitive writes require `x-step-up-token` issued by POST `/api/security/reauth` with `{password}`; expires in five minutes, bound to owner session. SSE GET `/api/events` sends `snapshot` events containing DashboardSnapshot and heartbeat comments. Initial GET `/api/dashboard` returns same shape.

GET `/api/settings` -> `{settings, version, assignments}`. PUT settings -> `{settings: Settings, expectedVersion: number}`. GET `/api/providers` -> ProviderView[]. POST providers -> `{config: ProviderConfig, secrets: ProviderSecrets}`. PUT `/api/providers/:id` -> `{config, secrets?, expectedVersion}`. DELETE provider and POST `/api/providers/:id/probe`, GET `/:id/models`. PUT `/api/assignments` -> ModelAssignment. Secrets never returned. GET `/api/skills` -> SkillDefinition[]. GET `/api/table/:name?page=1&pageSize=20&search=&status=` -> TablePage. GET same path `/export` -> CSV. GET `/api/detail/:name/:id` -> stored record. POST `/api/control` -> `{action:'pause'|'resume'|'emergency'|'paper'|'activate-live'}`. POST `/api/orders/:id/cancel`, `/replace` -> `{price, shares}`. POST `/api/wallet/check` refreshes readiness. GET `/api/wallet` -> public readiness/configured state only. GET `/api/market/:id/history` -> actual price history.

Auth: Better Auth endpoints `/api/auth/*`, email/password only, signup disabled. GET `/api/auth/get-session`, POST `/api/auth/sign-in/email` and `/sign-out` (Better Auth standard). No browser storage of keys/passwords/session tokens. Setup via owner CLI. Paper defaults have no trades/equity gains until actual worker results.
